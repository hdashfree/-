# Economic Fingerprint

2023년 산업연관표를 활용하여 산업별 투입구조를 "경제적 지문"으로 시각화하는 웹앱입니다.

## 주요 기능
- 대분류(33), 중분류(83), 소분류(165), 기본부문(380) 지원
- 국산투입계수(Ad) 기반 산업별 지문 시각화
- 최종수요 증가에 따른 생산·수입·부가가치 유발효과 계산
- 12개 원자료 시트 탐색

## 사용 방법
1. 첫 화면에서 산업분류 자료를 불러옵니다.
2. 산업을 선택하고 **지문 생성** 버튼을 눌러 산업별 구조를 확인합니다.
3. 시뮬레이터에서 산업과 증가액을 입력하여 파급효과를 계산합니다.
4. 원자료 탐색에서 각 시트와 행·열 값을 직접 조회할 수 있습니다.

## 배포
GitHub Pages 정적 웹앱으로 배포하며, 브라우저 내 Pyodide 환경에서 Python(model.py)을 실행합니다.

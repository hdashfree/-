# 산업의 지문

한국은행의 2023년 산업연관표(생산자가격)를 활용해 산업별 중간재 투입구조를 시각화하고 최종수요 증가에 따른 생산·수입·부가가치 유발효과를 계산하는 웹앱입니다.

[웹앱 열기](https://hdashfree.github.io/-/)

## 사용법

1. 대분류(33개), 중분류(83개), 소분류(165개), 기본부문(380개) 중 하나를 불러옵니다. 화면에 ‘준비 완료’가 표시되면 분석할 수 있습니다.
2. 산업명이나 코드로 원하는 산업을 찾아 선택한 뒤 지문 생성을 누릅니다. 지문 그래프와 국산투입계수가 높은 5개 부문을 확인할 수 있습니다.
3. 시뮬레이터에서 산업과 국내 생산물의 최종수요 증가액을 입력한 뒤 시나리오에 추가를 누릅니다. 여러 산업을 추가할 수 있으며 파급효과 계산을 누르면 결과가 표시됩니다.
4. 원자료 탐색에서 12개 시트 중 하나를 선택하고 산업명이나 코드로 행과 열을 검색합니다.

### 산업의 지문이 의미하는 것

지문은 **선택한 산업이 제품을 만들 때 어떤 재료·부품·서비스를 얼마나 사용하는지**를 곡선으로 표현한 그림입니다. 선택한 산업의 **열**을 기준으로 각 공급 부문의 **행**에서 국산투입계수와 수입투입계수를 가져옵니다. 산업마다 사용하는 중간재의 조합과 비중이 달라 지문 모양도 달라집니다.

굵은 선은 **국산 중간재**이며 가는 선은 **수입 중간재**의 투입 패턴을 나타냅니다. 두 패턴은 각각 크기를 조정하고 인접한 값을 평균 내어 곡선으로 그립니다. 지문의 굴곡으로 투입 패턴을 살펴보고 정확한 계수는 ‘주요 연결 산업 Top 5’와 원자료 표에서 확인할 수 있습니다. Top 5는 국산투입계수가 큰 순서입니다.

투입계수는 산출액 1단위당 중간재 투입액의 비율입니다. 예를 들어 자동차용 엔진의 기타 전기장비 국산투입계수 0.1094는 자동차용 엔진을 100원어치 생산할 때 국산 기타 전기장비가 약 10.94원어치 투입된다는 뜻입니다.

#### 최종수요 증가의 파급효과

입력한 최종수요 증가액을 산업별 벡터 f로 구성합니다. 생산유발계수 행렬은 국산투입계수 행렬 Ad와 단위행렬 I를 사용해 L = (I − Ad)⁻¹로 구합니다. 웹앱은 각 분류의 원본 엑셀에 수록된 유발계수 행렬을 사용해 다음과 같이 계산합니다.

- 생산유발액 = 생산유발계수 행렬 × f
- 수입유발액 = 수입유발계수 행렬 × f
- 부가가치유발액 = 부가가치유발계수 행렬 × f

최종수요 증가액과 유발액의 단위는 **백만원**입니다. 예를 들어 1000을 입력하면 선택한 산업의 국내 생산물에 대한 최종수요가 10억원 증가할 때의 파급효과를 계산합니다.

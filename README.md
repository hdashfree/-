# 산업의 결

**2023년 한국 산업연관표를 활용한 산업구조 탐색 및 파급효과 분석 웹사이트**

- [웹사이트 열기](https://hdashfree.github.io/-/)
- 자료: 한국은행, 2023년 산업연관표(생산자가격 기준)
- 제공하는 상품 분류: 통합대분류 **33개**, 통합중분류 **83개**, 통합소분류 **165개**, 기본부문 **380개**
- 브라우저에서 Pyodide를 통해 Python 분석 코드를 실행합니다. 별도 서버 설치 없이 GitHub Pages에서 작동합니다.

## 사용법

1. **분류 선택:** 대분류·중분류·소분류·기본부문 중 하나를 클릭하고 `준비 완료` 표시가 나오면 분석을 시작합니다.
2. **산업의 지문:** 산업명·코드를 검색해 선택합니다. 해당 산업을 생산할 때 투입되는 국산·수입 중간재의 계수를 원형 패턴으로 나타냅니다. `주요 국산 중간재 투입 Top 5`에서 정확한 계수를 확인할 수 있습니다.
3. **산업 비교:** 비교할 두 산업을 선택하고 `비교 분석`을 누릅니다. 두 산업의 지문과 국산·수입투입계수 합계, 중간재 중 국산 투입 비중을 비교합니다.
4. **파급효과 분석:** 국내 최종수요가 증가할 산업과 금액(백만원)을 입력하고 `추가하기`를 누른 다음, `파급효과 계산`을 누릅니다. 여러 산업을 추가해 한 번에 계산할 수 있습니다. 결과는 CSV로 내려받을 수 있습니다.
5. **원자료 검색:** 원자료 12개 시트에서 행과 열을 찾아 수치를 확인합니다.

## 지문이 의미하는 것

지문은 **선택한 산업을 생산하는 데 필요한 중간재 투입구조**를 시각화한 것입니다. 산업연관표의 행렬에서 **열은 생산하는 산업**, **행은 투입되는 공급 산업**을 뜻합니다. 따라서 선택 산업의 **열**에 속하는 국산투입계수 `Ad[i,j]`, 수입투입계수 `Am[i,j]`를 읽습니다.

- 상대적으로 **굵은 선**은 국산투입계수, **가는 선**은 수입투입계수의 패턴을 표현합니다.
- 각 계수는 시각적으로 구분되도록 변환·보간하여 표시합니다. 따라서 **선의 길이나 모양 자체가 정확한 금액·계수를 뜻하지는 않습니다.** 정확한 숫자는 지문 아래의 통계·Top 5 또는 원자료에서 확인해야 합니다.
- 각도를 배치하는 순서는 표에 있는 산업코드 순서에 따른 것으로, 각도 자체에 별도의 경제학적 의미는 없습니다.
- 예를 들어 `Ad[i,j] = 0.10`이라면 `j` 산업의 산출액 100원당 `i` 부문의 국산 중간재가 10원 투입된다는 의미입니다.

## 분석 방법

### 1. 산업의 투입구조

국산투입계수 행렬 `Ad`, 수입투입계수 행렬 `Am`에서 선택 산업 `j`의 열을 읽습니다. 각 산업에서 투입되는 중간재의 계수 합계는 다음과 같습니다.

- 국산투입계수 합계 = `Σ_i Ad[i,j]`
- 수입투입계수 합계 = `Σ_i Am[i,j]`
- 중간재 중 국산 투입 비중 = `Σ_i Ad[i,j] / (Σ_i Ad[i,j] + Σ_i Am[i,j]) × 100%`

마지막 비중은 **중간재 투입만** 비교하며 임금·이윤 등 부가가치는 포함하지 않습니다.

### 2. 최종수요 증가의 파급효과

국내 생산물에 대한 최종수요 증가 벡터를 `f`라 할 때, 다음 행렬을 활용합니다.

- 생산유발계수 행렬 `L = (I − Ad)⁻¹`
- 수입유발계수 행렬 `M = Am × L`
- 부가가치유발계수 행렬 `V = diag(v) × L` (`v`는 산업별 부가가치계수)

웹앱은 원본 산업연관표에 수록된 유발계수 행렬을 읽고 검증한 뒤 아래와 같이 계산합니다.

- 생산유발액 = `L × f`
- 수입유발액 = `M × f`
- 부가가치유발액 = `V × f`

최종수요 증가액과 각 유발액의 **단위는 백만원**입니다. 예를 들어 `1000`을 입력하면 10억원의 최종수요 증가를 뜻합니다. 투입계수·유발계수 자체는 **무차원 계수**입니다.

# 과제물1: 산업연관표분석 웹앱

2023년 산업연관표(생산자가격)를 이용하여 원자료 탐색과 국내 최종수요 증가에 따른 산업별 파급효과를 분석하는 웹앱입니다. 브라우저에서 Pyodide와 Python으로 계산하고 GitHub Pages에 게시합니다.

**웹앱 주소:** https://hdashfree.github.io/-/

## 분석 자료

- **기본부문:** `data/io-2023.xlsx` (380개 부문)
- **소분류:** `data/투입산출표_생산자가격_통합소분류.xlsx` (165개 부문)
- **중분류:** `data/투입산출표_생산자가격_통합중분류.xlsx` (83개 부문)
- **대분류:** `data/투입산출표_생산자가격_통합대분류.xlsx` (33개 부문)

각 파일은 12개 시트로 구성되어 있고, 거래표·투입계수표·생산유발계수표·수입유발계수표·부가가치유발계수표·최종수요 항목별 유발액을 포함합니다. 자료 출처는 한국은행 2023년 산업연관표(연장표)입니다. 웹앱의 분류는 상품부문 기준입니다.

## 사용 방법

1. 웹사이트를 열고 `기본부문`, `소분류`, `중분류`, `대분류` 중 하나의 **불러오기** 버튼을 누릅니다. 준비 완료와 검증 통과 메시지를 확인합니다.
2. **원자료 탐색**에서 시트를 선택하고 행 이름 또는 산업코드로 검색합니다. 아래 표에서 각 열의 코드·이름·원자료 값을 확인합니다.
3. **시뮬레이터**에서 산업을 검색하고 국내생산물 최종수요 증가액(백만원)을 입력한 뒤 `시나리오에 추가`를 누릅니다. 여러 산업을 추가할 수 있습니다.
4. `파급효과 계산`을 누르면 생산·수입·부가가치 유발액 합계, 산업별 결과, 생산유발액 상위 산업이 표시됩니다. `CSV 다운로드`로 모든 산업의 결과를 저장할 수 있습니다.
5. 다른 분류의 자료를 불러오면 이전 시나리오는 초기화됩니다. 분류 수준이 다른 결과를 비교할 때는 같은 금액을 해당 분류에 맞게 입력해야 합니다.

## 계산 및 분석 방법

- **국산투입계수행렬:** `Ad`, **수입투입계수행렬:** `Am`
- **생산유발계수행렬:** `L = (I - Ad)^(-1)`
- **수입유발계수행렬:** `M = Am × L`
- **부가가치유발계수행렬:** `V = diag(v) × L` (여기서 `v`는 부가가치율 벡터)
- **최종수요 증가 벡터:** `f` (단위: 백만원)
- **생산유발액:** `x = Lf`
- **수입유발액:** `m = Mf`
- **부가가치유발액:** `a = Vf`

각 분류의 엑셀 파일에 이미 제공된 유발계수행렬을 사용합니다. **다른 분류의 유발계수를 단순 합산하지 않습니다.** `model.py`가 `(I - Ad)L ≈ I`, `AmL ≈ M`, `diag(v)L ≈ V`인지를 검증하고, 최대 절대 잔차가 `1e-8` 미만인 경우 분석을 허용합니다.

거래액과 유발액의 단위는 **백만원**입니다. 투입계수·유발계수는 금액이 아닌 비율 또는 승수이므로 단위를 혼동하지 않아야 합니다. 시트마다 금액/계수/요약 지표를 구분하여 해석합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면과 결과 표 |
| `style.css` | 화면 디자인 (교수님 예제 원본 유지) |
| `app.js` | 검색, 시뮬레이션 화면 처리 (교수님 예제 원본 유지) |
| `multi.js` | 4가지 산업분류의 엑셀 파일 선택과 로딩 |
| `worker.js` | 별도 브라우저 작업 공간에서 Pyodide 실행 (교수님 예제 원본 유지) |
| `model.py` | 엑셀 검증, 산업연관분석 계산 (380부문 제한을 4가지 분류로 확장) |
| `data/*.xlsx` | 2023년 분류별 산업연관표 |

개인정보, 비밀번호, 접근 권한이 없는 자료는 공개 저장소에 업로드하지 않습니다.
